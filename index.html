The problem

Challenges are organized in chats and get lost along the way

Groups of friends start habit challenges, but evidence, votes, and points become scattered among messages. Over time, the challenge is abandoned because there is no proper follow-up or group support.

Target user

University students who create habit challenges with friends or classmates in small groups: reading, drinking water, studying, exercising, practicing a language, and more.

Need

Centralize the active challenge, completion evidence, voting, points, streak, and group ranking in one place.

Why challenges are abandoned

Without a dedicated space, no one knows for sure who completed the challenge, there is no fair comparison between participants, and group motivation fades.

Web application justification

Why the tools they already use are not enough

PlayReal is a web application, not a native mobile app. It needs collaborative follow-up, statistics, and daily updates from several users at the same time, which generic tools do not handle well.

WhatsApp / Instagram

They are useful for communication, but they do not track points, rankings, or an organized completion history. Evidence gets lost between messages.

Spreadsheet

It requires someone to update it manually for everyone. There is no visual evidence, voting, or motivating experience for the group.

PlayReal (web)

One place accessible from any browser, with automatic follow-up, evidence voting, and real-time ranking for the whole group.

The solution

A simple flow from start to finish

PlayReal organizes each challenge into a clear flow that every group member can follow without confusion.

Group → Challenge → Evidence → Voting → Scoring → Ranking
Target user

Designed for small groups of students

University students who want to stay motivated with habits such as reading, studying, exercising, drinking water, or avoiding unnecessary spending, alongside friends or classmates who support their progress.

User stories

Stories in the As a / I want / So that format

Create a private group

As a user, I want to create a private group so that I can invite my friends and participate in challenges with them.

Check the active challenge

As a participant, I want to check the active challenge so that I know what I need to do and when I need to complete it.

Upload evidence

As a participant, I want to upload a photo with a comment so that I can prove that I completed the challenge.

Vote for evidence

As a participant, I want to vote for a submission so that I can help choose the best participation.

View the ranking

As a participant, I want to view the group ranking so that I know my position and points.

AI usage

Transparency about AI usage

Prompt used: How can I implement CSS in my existing index file, which currently has no visual styling? Give me basic examples and commands for styling.

What AI contributed: For the CSS in our index, we defined color variables and base styles to keep everything consistent. We used position: sticky in the header so it remains visible without covering content while scrolling. CSS Grid was applied to the hero and the cards for the problem, justification, stories, and checklist, while Flexbox was used in the navigation, buttons, and form. We added focus states to inputs for accessibility. The page was also built mobile-first, with breakpoints at 768px and 1280px so it works well on mobile, tablet, and desktop.

What was modified and why: The team manually adjusted the text in each section to make it closer to how we describe the project, changed the color palette proposed by AI to better align with PlayReal's visual identity, reorganized information in some sections so the flow is easier to understand, and added sections that AI had not initially included to better cover the evaluation criteria.

Evaluation checklist

Phase 1 acceptance criteria

  • A real problem identified in the context of chats and social media, with disorganized evidence.
  • A specific user: university students who complete challenges with friends.
  • An unmet need: no centralized space for evidence, votes, points, and ranking.
  • Web application justification compared with WhatsApp, Instagram, and a spreadsheet.
  • At least three user stories in the As a / I want / So that format.
  • A public Figma link with the annotated web Home screen.
  • GitHub Pages deployment with a URL that responds with HTTP 200.
